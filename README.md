# EasyReels — downloads

Sermon clips for social, made on your Mac.

**[Download the latest version](https://github.com/gulfvideo/easy-reels-releases/releases/latest)**

This repository holds the built app only. The source is private.

---

## Installing

1. Download the `.dmg` from the link above.
2. Open it and drag **EasyReels** to **Applications**.
3. The first time you open it, macOS will refuse and say it "cannot be opened because
   Apple cannot check it for malicious software." That is expected — see below.

### Getting past that first message

EasyReels isn't signed with an Apple Developer ID, so macOS blocks it the first time. This
is the same message you get for any app from a small developer who hasn't paid Apple's
yearly fee.

1. Try to open EasyReels once and let it be blocked. Click **Done**.
2. Open **System Settings › Privacy & Security**.
3. Scroll down. There'll be a line about EasyReels being blocked, with an **Open Anyway**
   button. Click it.
4. Confirm, and it opens.

You only do this once. Updates install themselves and never ask again.

> Right-clicking and choosing *Open* used to work for this. It doesn't on current versions
> of macOS — the Privacy & Security route is the one that works.

## Requirements

- **macOS 26 or later**, on an Apple Silicon Mac (M1 or newer).
- **Apple Intelligence turned on**, if you want clips chosen for you. Without it,
  everything else still works and you pick the moments yourself.

## Updates

EasyReels checks for updates on its own and will offer them when they appear. You can also
check whenever you like: **EasyReels › Check for Updates**.

## Privacy

Everything happens on your Mac. Sermons are transcribed, read and rendered locally, and
nothing about them is uploaded anywhere. The only network request the app makes is to
check whether a new version exists.
